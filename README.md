# 🍽️ Zomato Restaurant Market Analysis

An exploratory data analysis project using Microsoft Excel to examine restaurant distribution, customer ratings, pricing patterns, and service availability across the Zomato dataset.

## 📌 Project Overview

This project analyzes **9,551 restaurant records across 23 attributes** to explore patterns in the restaurant industry and understand how factors such as location, ratings, pricing, and service availability are represented in the dataset.

The analysis was performed using Microsoft Excel, with data preparation, formula-based transformations, PivotTables, and visual dashboards.

## 🎯 Objectives

- Explore restaurant distribution across countries and locations.
- Analyze restaurant ratings and customer voting patterns.
- Examine restaurant price ranges and pricing distribution.
- Investigate online delivery and table-booking availability.
- Build an interactive, easy-to-understand dashboard to communicate findings.

| Filters & Sorting | Exploring and organizing records |

## 🔄 Project Workflow

1. **Data Inspection:** Examined the dataset structure, columns, and available records.
2. **Data Preparation:** Organized and cleaned the data for analysis.
3. **Data Transformation:** Used XLOOKUP to map country codes and logical formulas for conditional analysis.
4. **Exploratory Analysis:** Used filters and PivotTables to investigate restaurant distribution, ratings, votes, pricing, and service availability.
5. **Data Visualization:** Created charts and dashboard elements to present the analysis.
6. **Interpretation:** Examined the resulting summaries to identify patterns in the restaurant dataset.

## 📊 Key Areas of Analysis

The project explores the following dimensions:

- **Restaurant Distribution:** Geographic distribution of restaurants.
- **Customer Ratings:** Rating patterns and their distribution.
- **Customer Engagement:** Restaurant votes and customer interaction.
- **Pricing Analysis:** Average cost and price-range patterns.
- **Service Availability:** Online delivery and table-booking availability.
